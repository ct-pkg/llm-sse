## 1 承接条目

### EXT-LLM-01 包清单补 `publisher` / `ns-root`，依赖改全名

- **来源编号**：包外事项清单 EXT-LLM-01（原提案 §10 S4）。
- **要做什么**：`ct.pkg` 增补 `publisher` 与 `ns-root` 两个键；三条 `dep`（http / sse / json）由短名改为全名形态 `<publisher>/<name>@<range>`。
- **前置能力**：C1（读 `publisher`）、C2（`ns-root` 进 `-I`）。C3 属构建期保障，不作为本条的验收前置。
- **验收方式**：
  1. `ct.pkg` 含 `publisher`、`ns-root`，值非空且与 store 中的记录一致（C1 就绪后核对）；
  2. 三条 `dep` 全部为 `<publisher>/<name>@<range>`，无短名残留（可 grep 核对）；
  3. C2 就绪后，带 `ns-root` 的 `-I` 能解析到本包依赖，构建不因命名空间缺失失败；
  4. 反向判据：任一 `dep` 仍为短名、或 `publisher` / `ns-root` 缺失 → 本条未完成。
- **状态**：`blocked`（等待 C1 / C2）。
- **与既有文档的张力**：见 §2 W-01 的矛盾点 2。
